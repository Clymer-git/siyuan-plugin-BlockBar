# 块捷坞·兔脱

一个思源笔记插件：在移动端键盘工具条正上方叠加一排可自定义的快捷工具栏，边打字边点，不用为了一个动作把键盘收起来。

## 功能

- 快捷工具栏：默认 9 个面板（标题 / 列表 / 插入 / 引述 / 表格 / 块 / 样式 / 公式 / 图表），可自由增删、排序、改图标。
- 按钮与面板都能单独启用 / 停用；面板里可以继续放动作、设置命令或快捷短语。
- 键盘友好：工具栏动作默认不收起软键盘；只有需要弹出原生菜单或对话框时才自动收起，菜单关闭后不强制弹回。
- 动态能力发现：图标列表和菜单项从运行中的思源实时读取，思源新增图标或菜单项通常无需更新插件。
- 设置页内置「诊断」：每个按钮是动态获取、回退获取还是不可用，一眼可见。
- 顺序调整：在设置页按住按钮左侧的手柄拖动即可排序，拖到屏幕上下边缘会自动滚动。

## 环境要求

- 思源笔记 **3.8.4 或更新版本**。
- 移动端 App（Android / iOS / 鸿蒙）或移动端浏览器。

> 自 v0.8.68 起，插件不再提供独立的表格工具栏：思源 3.8.8 的原生表格能力已经足够强，在插件里再复刻一套只会增加维护成本。表格单元格内的「光标不丢、键盘不塌」仍由插件原有的键盘守卫负责。

## 安装

1. 下载 `package.zip`。
2. 打开思源 → 设置 → 集市 → 已下载 → 从安装包安装（选择该 zip）。
3. 启用插件。
4. 打开任意文档，点一下正文段落唤出键盘。

## 说明

- 本插件使用自己独立的配置目录，不读取、不修改其他插件的数据。
- 旧版本配置里若带有表格工具栏的按钮，导入时会被安全丢弃；下次保存后该字段自然消失，不需要手动迁移。
